IMPORTANT — Desktop Offline Mode (SQLite sync):
When adding a new Alembic migration in the backend (new table, new column, etc.),
you MUST also update the desktop SQLite schema to keep offline mode in sync:
  1. Add a new migration file in desktop/src/db/migrations/ (e.g. 003_<name>.ts)
  2. Register it in desktop/src/db/schema.ts
  3. Update the corresponding repository in desktop/src/db/repositories/
  4. Update desktop/src/ipc/offlineApi.ts if new API endpoints are involved
Skipping this will cause offline mode to miss the new data.
